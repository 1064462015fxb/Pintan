# 本次上架图片调研与测试范围

调研日期：2026-09-13。淘宝、京东没有对所有类目通用且本次可公开核验的统一“必须多少张”结论。发布后台按类目校验，不能把设计建议说成官方硬性门槛。

本商品建议的首版素材包（项目策划建议）：

- 5张轮播展示：干净商品全貌、使用场景、功能细节、规格装量、无额外文案白底图。顺序以实际千牛/京麦要求调整。
- SKU图：每个需要视觉区分的规格1张。本商品30/60/90只可使用同款实拍底图加准确装量标签，不能画成不同产品或虚构包装。
- 详情图：建议4–6个信息模块，覆盖用途、安装、真实细节、规格、使用注意。缺少尺寸或承重证据时不编造图表。
- 同一张图可以在轮播与详情复用，不必为了凑数生成重复图。缺少背面实拍时不得AI捏造背面。

资料：

- 淘宝官方发布字段说明：https://developer.alibaba.com/docs/doc.htm?articleId=108956&docType=1&treeId=1 。支持商品图、描述、SKU及属性组织；类目要求需查询具体类目。
