# 采集到上架素材

1. 在采集页复核文字和图片，点击确认。商品按真实商品 ID 幂等写入稳定选品，不写入爆款表。
2. 进入稳定选品。资料完整时自动计算原有五维分数；缺项显示“待补充评分资料”。展开“采购规格与评分资料”，选择实际规格及价格，补充有依据的评分输入，保存并计算。
3. 点击对应商品的“选择并创建内容母版”。内容页自动选中该商品；进行 AI 风格诊断，人工选择风格和淘宝或京东。
4. 生成并复核文案。后台母版使用当前已确认事实，平台内容保留标题、卖点、属性/参数和详情模块。
5. 在素材与成品中确认图片使用权，再生成三张平台图。商品主体来自真实原图，模型生成背景。可下载成图；缺少可用原图或授权时不可生成。

采购价不等于零售价。供应商物流服务不能直接变成本店服务承诺。正式发布前仍需在千牛/京麦确认目标类目、必填属性、逐 SKU 零售价和库存、运费及图片一致性。本版本生成待审核素材，不自动登录卖家后台或发布商品。

淘宝字段组织参考官方商品发布示例：https://developer.alibaba.com/docs/doc.htm?articleId=108956&docType=1&treeId=1 （2026-09-12核验）。
京东帮助入口：https://h5.jd.com/article/901.html 。当前模板为项目组织建议，具体类目限制待京麦后台复核，不宣称已获取实时后台规则。

测试：test_selection_intake.py 覆盖确认入池、重复确认、缺项不造分、精确规格价格、数值范围及重复计算一致性。相关采集映射、内容与媒体测试一起运行。
