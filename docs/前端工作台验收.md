# 前端工作台优化

## 使用入口

- 数据采集：`#collector/batch`。批量稳定采集为默认入口；爆款平替采集仅预留。单链接、手工补录和历史记录收起在底部。
- 选品：`#selection/stable` / `#selection/trending`。每页10条，AI建议和逐SKU价格编辑点击展开；待补充商品从状态筛选进入。
- 内容生产：`#content`。完成步骤默认收起，授权和事实门禁保留。实际图片进度区分成功与失败；文字任务不展示虚构百分比。
- 铺货：`#distribution` → 商品预览 → 确认内容包。至少一张成功图和有效文案可以确认，后端仍核对事实、风险与所选原图授权。平台实际发布由用户完成。

## 数据兼容

- 列表封面保存在独立的 `product_covers`，不会变成授权素材。快速文字采集最多额外下载一张封面；失败不影响采集与评分。
- 历史商品缺少封面显示占位图，可以点击“补采封面”。新下载不运行OCR、视觉分类或抠图。
- `listing_packages`保存固定文案及图片版本；新生成内容不覆盖已确认内容包。同一组合重复确认复用记录。
- 旧 `#selection/batch` 地址自动进入数据采集；商品预览、内容包详情支持刷新及返回。
- 数据库迁移为新增表，保留业务记录；服务启动前已保存SQLite备份至 `data/backups/`。

## 验证方式

- `tests/test_workbench_flow.py`：封面隔离、危险地址、授权门禁、最小内容包、幂等确认、旧包保留、真实进度与取消后进度保留。
- `tests/test_workbench_ui.cjs`：隔离模拟21条商品，验证10/10/1分页、跨页选择、刷新、筛选重置、默认折叠、占位页不提交、三级铺货、部分完成、无百分比阶段及窄屏。
- `tests/test_media_controls.cjs`：模拟媒体响应，验证规划、中断、刷新恢复。不会进行付费生成。
- `scripts/verify_workbench_live.cjs`：只读浏览真实本机商品、采集入口、铺货预览与内容返回页面；截图保存在 `artifacts/workbench/`。

真实页面验收不替用户确认授权或内容包；三级确认操作在隔离测试中验证。未重新执行1688批量采集及付费图片生成。
