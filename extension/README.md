# 品探浏览器助手 2.7

需要Chrome/Edge 120及以上。本扩展只访问任务指定的1688、淘宝、京东、抖音/巨量百应可见页面及本机8010服务；不读取Cookie、Token或站点存储。

1. 启动品探，在工作台“数据采集”中点击“生成配对码”。
2. Chrome打开 `chrome://extensions`，Edge打开 `edge://extensions`，启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择本文件所在的 `extension` 文件夹（或工作台下载的ZIP解压后文件夹）。已有旧版请点“重新加载”。
4. 点击浏览器工具栏中的品探助手，输入工作台8位配对码，点击“配对”；显示已连接后可以关闭弹窗。
5. 工作台只填写1688商品详情链接，点击“开始采集”。浏览器已有同商品标签时复用，否则新开，不覆盖其他网页。
6. 若显示等待人工处理，在这个Chrome/Edge完成登录或验证码，再在工作台点“继续采集”。Codex内置浏览器的登录状态不会转移到Chrome/Edge。

批量稳定采集还支持“以图搜图”：在工作台上传或粘贴一张 PNG、JPG 或 WebP 参考图，再点击开始。扩展只把该用户选择的图片提交给1688的页面图搜控件；不读取或传输Cookie、Token、LocalStorage及完整请求头。若1688页面未提供可操作的图搜控件，任务会停在“等待人工处理”，不会捏造搜索结果。

爆款平替采集会按用户选择依次读取淘宝、京东和抖音的搜索结果；抖音有百应权限时先尝试百应，否则自动退回公开商品搜索。晋级爆款再触发1688关键词搜索和以图搜图。

铺货页面确认淘宝内容包后，可让扩展打开千牛商品发布页并填写能够可靠识别的标题和普通详情文本。扩展不会选择类目、SKU、库存、运费模板或资质，不会上传图片，也不会点击提交审核或发布；这些内容必须由用户在千牛中核对。完整图片、SKU表和检查清单请从铺货页下载上架包。

关闭弹窗不影响任务；关闭整个浏览器会断开助手。重新打开后可重连，中断任务需要显式重试。
工作台分别展示本次采集和商品历史素材；无图片只会部分完成，不伪造主图。
下载不会自动确认商业使用权；授权仍由用户在现有素材流程确认。

连接检查：本机服务必须为 `http://127.0.0.1:8010`。配对码5分钟有效、一次性使用、最多5次错误尝试。
连接凭据只存在扩展本地，服务端只保存其SHA-256；不向内容脚本开放凭据。
后台按照Chrome官方WebSocket机制每20秒保活，alarms每30秒唤醒重连：
https://developer.chrome.com/docs/extensions/how-to/web-platform/websockets
